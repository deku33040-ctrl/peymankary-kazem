سایت پیمانکاری کاظمی — نسخه ۳ (صفحه‌ساز کشیدن‌ورها)
====================================================

اجرا (محلی)
-----------
1) python -m venv .venv && source .venv/bin/activate     (ویندوز: .venv\Scripts\activate)
2) pip install -r requirements.txt
3) python app.py
   • در اولین اجرا یک رمز تصادفی برای مدیر در ترمینال چاپ می‌شود؛ همان‌جا یادداشتش کن و بعد از ورود تغییرش بده.
   • یا از قبل تعیین کن:  ADMIN_USERNAME=admin  ADMIN_PASSWORD=رمز-قوی-حداقل-۱۲-نویسه
   • فراموشی رمز:  python app.py reset-admin
4) سایت: http://127.0.0.1:5000   |   پنل: http://127.0.0.1:5000/admin/login

ارتقا از نسخه قبلی
-------------------
kazemi.db و پوشه‌های static/uploads و static/fonts را نگه دار و بقیه فایل‌ها را جایگزین کن (پشتیبان بگیر).
در اولین اجرا چیدمان قبلی و «بخش‌های اختصاصی» قدیمی خودکار به بلوک تبدیل می‌شوند.

صفحه‌ساز  (پنل ← «صفحه‌ساز و تنظیمات تماس»  یا  /admin/builder)
------------------------------------------------------------
• ستون راست: بلوک‌ها را بکش و در صفحه رها کن (یا فقط روی بلوک بزن). روی موبایل از دکمه‌های ↑ ↓ استفاده کن.
• بخش‌های اصلی (بنر، درباره، خدمات، نمونه‌کارها، مجله، جمله شاخص، تماس) را جابه‌جا، مخفی یا حذف کن و دوباره اضافه کن.
• بلوک‌های جدید: متن، تصویر، دکمه/فراخوان، آمار و اعداد، سوالات متداول، فاصله خالی (هر چندتا که بخواهی).
• ستون چپ، تب «بلوک»: متن‌ها و تصاویر همان بلوک. تب «تماس»: شماره، واتساپ، تلگرام، اینستاگرام، ایمیل.
  تب «ظاهر و سایت»: رنگ، فونت، افکت‌ها، نام شرکت، شعار، لوگو، فوتر و سئو.
• دکمه «پیش‌نمایش» سایت را همان‌جا نشان می‌دهد؛ «ذخیره و انتشار» تغییرات را زنده می‌کند.
• در عنوان‌ها، کلمه‌ای که بین ستاره بگذاری (*مثل این*) برجسته می‌شود.

شماره تماس، واتساپ و تلگرام
----------------------------
• یک جا عوض کن، همه‌جا اعمال می‌شود (هدر، فوتر، بخش تماس، دکمه‌های شناور).
• شماره: فارسی یا انگلیسی، با +کد کشور یا با صفر. اگر با صفر شروع می‌شود «کد کشور» (مثلاً 93 یا 98) را پر کن.
• واتساپ خالی = همان شماره تماس. تلگرام: @نام‌کاربری، لینک t.me یا شماره. لینک‌های نامعتبر نمایش داده نمی‌شوند.
• زیر فرم، لینک‌هایی که ساخته می‌شود زنده نمایش داده می‌شود تا قبل از ذخیره مطمئن شوی.

انتشار روی سرور
----------------
• سرور تولید:  waitress-serve --listen=0.0.0.0:8000 app:app
• پشت nginx:  TRUST_PROXY=1  (برای دیدن IP واقعی) و در HTTPS: SESSION_COOKIE_SECURE=1
• SECRET_KEY را به‌صورت متغیر محیطی بده. kazemi.db و static/uploads باید روی دیسک پایدار باشند و پشتیبان بگیری.
• تست: python -m unittest -v
